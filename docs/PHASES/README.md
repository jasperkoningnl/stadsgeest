# Faseoverzicht

**Doel:** per fase compact de status, resterende verplichtingen en afsluitvoorwaarde tonen.
**Status:** gezaghebbende voortgangsindex.

Het volledige `../Stadsgeest_uitbreidingsplan_Claude.md` blijft leidend. Deze
bestanden vervangen de specificatie niet en mogen onderdelen daaruit niet
stilzwijgend laten vervallen.

| Fase | Status | Document |
|---|---|---|
| 0 — inventarisatie en contracten | mijlpaal bereikt; slotaudit nodig | `phase-0.md` |
| 1 — entiteitenfundament | productiepad aanwezig; slotaudit nodig | `phase-1.md` |
| 2 — eventbronnen en graph matching | productiepad actief; slotaudit nodig | `phase-2.md` |
| 3 — sectorregisters en statistiek | actief | `phase-3.md` |
| 4 — periodieke en experimentele bronnen | gepland | `phase-4.md` |
| 5 — redactionele leerloop | gepland | `phase-5.md` |

Een fase is pas volledig gesloten wanneer ieder onderdeel uit het leidende plan
is uitgevoerd of met een zwaarwegende reden in `../DECISIONS.md` is afgeweken.
